# Xoia

## HUD CHANGES

    Game timer
    Round timer
    Trap timer
    Box hits counter
    Raygun tracker
    SPH meter (default start at 50)

## Game Monitor
### Trackers
Xoia automatically tracks the following:
- Round times
- Drops grabbed on every round
- Box hits
- Leapers
- Brutus
- Panzers
- Templars
### Available Commands
This commands were inspired by the [TIM](https://download.magicbennie.com/BlackOpsZombies/TIM/) tool for BlackOps
- `!help` →  Shows all of the commands.
- `!bs` →  Switches between console and steam backspeed. 
- `!bh` → Displays the ammount of times the box has been hit.

- `!dg <round>` -> Shows how many drops were grabbed

- `!times` → Displays time-related information for the game.  
- `!t` → Displays the total game time.  
- `!rt <round>` → Displays the round time.  
- `!timer <value>` → Changes the timer position.  
- `!tt` → Hides/Shows the trap timer.
- `!sph <round>` → Displays the SPH for the round.  

- `!zc <round>` → Displays the number of zombies in the given round.  
- `!tzc <start round> <end round>` → Calculates the total number of zombies from one round to another.  

- `!fb <list of weapons>` → Toggles RNG for the mystery box on or off.  
- `!box <location>` → Changes the starting location of the mystery box in maps with multiple starting locations.  
- `!fridge <weapon>` -> Inserts the weapon in the weapon locker.
- `!key <location / reset>` -> Changes the key spawn on MOTD, requires a `map_restart`.
- `!forcepap` -> Automatically restarts the game untill the Pack-A-Punch is in the green house, requires a `map_restart`.

- `!na` → Displays the next possible Avogadro round.  
- `!nb` → Displays the next possible Brutus round.  
- `!nt` → Displays the next possible Templars round.  
- `!np` → Displays the next possible Panzer round.  
- `!nl` → Displays the next possible Leapers round.  
- `!rounders` → Shows the history of special rounds.  
- `!panzers` → Shows the history of Panzers.  
- `!templars` → Shows the history of Templars.  
- `!leapers` → Shows the history of Leapers.  
- `!brutus` → Shows the history of Brutus.  
- `!avogadros` → Shows the history of Avogadros.  

- `!c <number>` → Changes the player's character model.  
- `!papcamo <value>` → Changes the Pack-a-Punch camo.
